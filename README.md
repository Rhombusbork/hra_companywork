# 제주대 정보 모아 보기 — 인수인계

HRA 20기 1조 기업실무 기획과제(바이브코딩 제주 로컬 웹서비스 MVP)를 이어서 할 사람을 위한 문서다. 2026-11-26 기준.

## 무엇을 만드나

제주대 공지는 본부, 학과, 생활관, 취업센터, 국제교류에 흩어져 있다. 장학금 공고는 일주일에 4건쯤 올라오는데 마감일은 제목이나 첨부 파일 안에만 있다. 학식은 식당마다 올리는 곳이 다르다.

그래서 이것들을 한 화면에 모은다. 학과·키워드·분류(장학, 행사 …)를 정해 두면 그에 맞는 글만, 마감이 가까운 순으로 보여 준다. 로그인은 없고, 관심사는 브라우저에 저장한다.

```
GitHub Actions (하루 몇 번) → 학교 게시판·식단 읽기 → JSON → GitHub Pages
브라우저: JSON 을 받아 관심사(브라우저 저장)로 거름
```

- 학과가 본부 글을 다시 올리면 글 번호(seq)가 새로 붙는다. 수집기가 제목으로 묶어 본부 글에 "함께 게시"로 붙인다.
- 1호관 점심·저녁 메뉴는 인스타그램 이미지에만 있다. 직접 긁지 않고 링크만 둔다.
- jedaero 는 robots.txt 가 없어서(404) 3쪽까지 본다. 나머지 학교 사이트는 첫 페이지만.

## 수집기 돌리기

```
pip install -r collector/requirements.txt
python collector/collect.py                 # site/data 를 갱신
python collector/collect.py --cache /tmp/c  # 받은 원본을 저장해 두고 다시 받지 않음 (고칠 때)
```

- 학과를 늘리려면 `sources.json` 의 `departments` 에 `site/data/departments.json` 의 id 를 넣는다.
- 한 곳이 실패하거나 0건이면 그곳은 이전 데이터를 쓰고, 끝날 때 실패로 끝난다(Actions 가 메일을 보냄). 원인은 `items.json` 의 `sources.<id>.error`.
- 화면 보기: 저장소 맨 위에서 `python3 -m http.server` 후 `/site/`.
