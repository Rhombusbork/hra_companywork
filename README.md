# 제주대 정보 모아 보기 — 인수인계

HRA 20기 1조 기업실무 기획과제(바이브코딩 제주 로컬 웹서비스 MVP)를 이어서 할 사람을 위한 문서다. 2026-11-23 기준.

## 무엇을 만드나

제주대 공지는 본부, 학과, 생활관, 취업센터, 국제교류에 흩어져 있다. 장학금 공고는 일주일에 4건쯤 올라오는데 마감일은 제목이나 첨부 파일 안에만 있다. 학식은 식당마다 올리는 곳이 다르다.

그래서 이것들을 한 화면에 모은다. 학과·키워드·분류(장학, 행사 …)를 정해 두면 그에 맞는 글만, 마감이 가까운 순으로 보여 준다. 로그인은 없고, 관심사는 브라우저에 저장한다.

```
GitHub Actions (하루 몇 번) → 학교 게시판·식단 읽기 → JSON → GitHub Pages
브라우저: JSON 을 받아 관심사(브라우저 저장)로 거름
```

## 지금까지 된 것

조사는 끝났다. 코드는 아직 한 줄도 없다.

- 정보원 조사 5개 (11/21): 본부 사이트, 학과 101곳, 학식·생활, 학교 밖 기관 45곳, 서브도메인 약 200개
- 종합과 실제 확인: [07_정보원_종합.md](제주_웹서비스_MVP/07_정보원_종합.md). 핵심 주소 21개를 직접 받아 봤다.

알아 둘 사실이 몇 개 있다.

- 학교 사이트는 본부부터 학과까지 거의 다 같은 CMS(artpq)라서 목록 파서 하나로 대부분 읽힌다.
- 장학 공지는 거의 다 본부 공지사항의 장학 분류(`outEvent.htm?category=323`) 한 곳에 있다.
- 학과가 본부 글을 다시 올리면 글 번호(seq)가 새로 붙는다. 중복은 제목 비교까지 해야 걸러진다.
- 1호관 점심·저녁 메뉴는 인스타그램 이미지에만 있다. 직접 긁지 않기로 했다(약관).
- 학교 서버가 중간 인증서를 보내지 않는다. 인증서 번들을 따로 만들어야 한다(07 5절).
