# 09. 서비스 요약 — 제주대 모아보기

다른 아이디어(① 자리있수다)와 같은 양식으로 정리했다. 2026-11-26 밤 기준(실제 수집이 붙고 v1·v2 를 합친 판). 11/27 화면 개편(React, 홈 칸 꾸미기, 처음 설정 3단계 복귀, 학식 끼니 탭)을 반영했다. 피드백 항목은 아직 정하지 않아서 [제안]으로 적었다.

## ② 제주대 모아보기 — 내 학과에 맞춘 제주대 공지·장학·학식 한곳에

- 사이트: https://rhombusbork.github.io/hra_companywork/ (11/26 v1·v2 합침. 옛 /v2/ 주소는 여기로 넘어감)
- 학과 링크: 주소 뒤에 `?dept=약학과` 처럼 붙이면 그 학과로 바로 시작

* **고객 문제:** 제주대 공지는 본부, 학과, 생활관, 진로취업센터, 국제교류처에 흩어져 있음. 장학 공고는 일주일에 4건쯤 올라오는데 마감일은 제목이나 첨부 파일 안에만 있어 놓치기 쉬움. 학과 근로장학생 모집, 졸업시험 안내처럼 학과 게시판에만 올라오는 글은 더 찾기 어려움. 학식도 식당마다 올리는 곳이 다름.
* **타깃:** 제주대 학부생 (보조 타깃: 대학원생, 기숙사생, 복수전공·교직 이수 학생)
* **핵심 가치:** 학과만 고르면 내 학과 공지와 나에게 필요한 학교 공지를 한 화면에, 마감이 가까운 순으로 보여 줌. 로그인 없이.
* **핵심 기능:**
  * 처음 온 사람에게 설정 3단계(나 → 볼 것 → 홈 화면). "건너뛰고 둘러보기"를 누르면 바로 홈. 학과를 고르면 학부/대학원·캠퍼스가 자동으로 채워지고, 계열에 맞는 분류가 더해짐(예: 어문 계열 → 국제교류). 학과 링크(`?dept=`)로 오면 묻지 않고 바로 홈
  * 내 학과 카드: 학과 게시판 글, 학과가 다시 올린 본부 글, 졸업요건·자격 글을 맨 위에 크게. 칩으로 유형을 거름(졸업·학사, 졸업요건·자격, 근로·학과장학, 교직, 취업·채용, 실습·특강, 행사)
  * 분류 카드와 칩: 학사(수업·등록·학적·학사일정), 장학, 생활관, 프로그램·행사(산학·현장실습·행사·봉사), 취업·인턴(인턴·채용·진로 프로그램), 국제교류
  * 마감 D-day와 새 글 표시. 마감일 옆에 출처를 붙임(제목 표기 / 게시판 칸). 머리에 "마지막 갱신" 시각
  * 오늘·달력 칸과 일정 탭: 오늘 일정, 이달 달력, 이번 주를 한 칸에. 일정 탭 달력에 마감·학사일정·북마크를 찍음
  * 홈 꾸미기: "홈 편집"(칸 길게 누르기)으로 칸을 옮기고, 크기를 바꾸고, 숨기고, 색(학교 색 안에서)을 고름. 배치는 이 브라우저에만
  * 북마크: 제목 옆 ☆과 글 상세 창. 휴대폰 캘린더 파일(.ics)로 내보내 하루 전 알림을 받음(서버 없이 알림을 대신하는 방법)
  * 오늘 학식: 백두관, 6호관, 1호관, 사라캠퍼스. 자주 가는 식당을 고르고 끼니 탭으로 봄. 지금 시간에 맞는 끼니가 먼저 열림
  * 키워드 모아 보기·숨기기, 정보원 숨기기, 설정 코드로 다른 기기에 옮기기
* **입력 항목:** 주전공(선택, 안 넣어도 씀), 복수전공·부전공, 학부/대학원, 캠퍼스, 기숙사 여부, 교직 이수 여부, 볼 분류, 학식 식당, 홈에 둘 칸, 표시할 것(새 글·마감 임박), 키워드
* **결과 화면 (기본 배치, 사용자가 바꿀 수 있음):** (학과가 없으면 맨 위에 "학과 넣기" 한 줄) 오늘·달력 → 가장 먼저 마감 · 그다음 마감 · 오늘 학식 · 이번 주 마감 수 → 내 학과 칸 → 내 키워드 → 분류 칸(모두에게 필요한 것 → 내 학과와 가까운 것 → 그 밖, 칸 위에 층과 "OO대학 추천"을 적음). 같은 글은 한 칸에만 보임. 글이 없는 분류는 칸을 만들지 않음. 글을 누르면 상세 창(게시일, 마감과 출처, 첨부 이름, 북마크) → 원문 링크
* **피드백 항목 [제안]:**
  * 응답자 유형(단과대, 학년, 기숙사 여부)
  * 문제 해결 만족도, 사용 편의성, 정보 신뢰도, 재사용 의향(각 5점 척도)
  * 가장 유용한 기능
  * 처음 설정에서 추천된 분류 중 뺀 것, 없어서 더한 것
  * 학년에 따라 보고 싶은 게 달랐는지(학년 입력을 뺀 판단 확인용)
  * 추가로 원하는 기능, 자유 의견
* **사용 데이터 (11/26 부터 실제 수집):**
  * 학과 104곳의 이름과 공지 게시판 주소: 실제 학과 홈페이지 전수조사([02-1](정보원_조사/02-1_학과_전수표.md))에서 만듦. 이 중 글을 모으는 학과 게시판은 약학·간호 두 곳(사용자 결정). 다른 학과를 고르면 "아직 모으지 않아요"와 게시판 링크를 보여 줌
  * 공지 약 200건: 본부 공지, 학생생활관, 국제교류, 진로취업 clip, 약학대학, 간호대학, 제대로 산학1번지, 중앙도서관에서 하루 4번 받음([collector/sources.json](../collector/sources.json))
  * 학식: 백두관·6호관·사라캠퍼스 학교 식단표를 하루 4번 받음. 1호관은 업체 사이트(천원의 아침밥)와 업체 인스타 글에서 읽음
  * 마감일: 제목에 적힌 날짜와 게시판 마감 칸만 씀. AI 추정 마감일은 아직 0건(다음 단계)
  * 학사일정 약 70건: 학교 학사일정 페이지에서 하루 한 번
  * 분류: 본부 공지의 분류 번호(학사 320, 수업 321, 등록 322, 장학 323, 행사 200, 봉사 197)를 먼저 따르고, 번호가 없으면 제목 키워드
  * 계열 추천: 단과대별 규칙. 일부는 학과 게시판의 실제 글이 근거(정치외교학과 교류수학 안내, 미술학과 해외파견 교류수학), 나머지는 짐작
  * 정렬: 마감이 남은 글은 마감 가까운 순, 나머지는 게시일 최신 순. 본부 글을 학과가 다시 올린 경우는 하나로 합침
  * 저장: 설정과 북마크는 브라우저에만. 서버, 로그인, DB 없음
* **갱신 방식 (지금 돌아가는 것):**
