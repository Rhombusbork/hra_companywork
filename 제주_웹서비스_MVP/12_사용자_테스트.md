# 12. 사용자 테스트

과제 조건은 "잠재 사용자 5명 이상 테스트, 피드백 정량화"다. 목표는 12/2~4 에 테스트하고 결과를 [13 피드백 분석표](13_피드백_분석표.md)에 옮기는 것이다.

## 1. 방법

- **5명 이상**, 제주대 학생. 단과대가 섞이면 좋다. 기숙사생 한 명쯤, 신입생 한 명쯤 [제안].
- **휴대폰으로** 한다. 학생들은 대부분 휴대폰으로 볼 것이다.
- 링크만 주고 설명은 하지 않는다. **옆에서 지켜보며** 어디서 멈추는지, 무엇을 잘못 누르는지 적는다. 도와 달라고 하면 "평소라면 어떻게 하실 것 같아요?"라고 되묻는다.
- 순서: 인터뷰(2절, 사이트 보여 주기 전) → 과제 시나리오(3절) → 폼 작성(4절). 한 사람에 15분 안팎.
- 테스트 주소: https://rhombusbork.github.io/hra_companywork/ (11/26 v1·v2 를 합친 한 판). 약학·간호 학생이면 `?dept=약학과`·`?dept=간호학과` 를 붙인 링크를 주면 학과 게시판 글까지 보인다
- 실제 데이터로 하는지, 예시 데이터로 하는지 테스트 기록에 적어 둔다.
- 이름·학번은 적지 않는다. A, B, C… 로만.

## 2. 인터뷰 (사이트 보여 주기 전에)

"이런 서비스 있으면 쓰겠어?"는 묻지 않는다. 예의상 "응"이라고 답하기 때문이다. 지난 일을 묻는다([03](03_문제_찾기_방법.md) C절, 『The Mom Test』).

1. 최근에 장학금·행사·학과 공지를 늦게 알았거나 놓친 적이 있어? 언제였어?
2. 그때 어떻게 알게 됐어? (친구, 단톡방, 에타, 학교 사이트…)
3. 학교 공지를 확인하려고 마지막으로 들어간 곳이 어디야? 몇 군데 봤어?
4. 일주일에 학교·학과 사이트에 몇 번쯤 들어가?
5. 학과 게시판은 따로 봐? 마지막으로 본 게 언제야?
6. 학식은 어떻게 확인해? 마지막으로 확인한 게 언제야?
7. 지금 공지 보는 방식에서 제일 귀찮은 게 뭐야?

## 3. 과제 시나리오 (사이트를 쓰면서)

각 과제마다 성공했는지, 걸린 시간, 막힌 곳을 적는다.

| 번호 | 과제 | 보는 것 |
|---|---|---|
| T1 | 처음 들어와서 "이게 뭐 하는 사이트인지" 말해 보기 | 10초 안에 알아보는지 |
| T2 | 장학 공지 중 마감이 가장 가까운 것 찾기 | 장학 카드·마감 표시를 찾는지 |
| T3 | 오늘 학식 보기 (자기가 가는 식당) | 학식을 찾는 데 걸린 시간 |
| T4 | 내 학과 넣기, 학과 공지 보기 | 학과를 넣는 곳을 찾는지, 넣고 싶어 하는지 |
| T5 | 관심 가는 글 하나를 북마크하고 원문 열기 | 북마크·원문 링크를 찾는지 |

시간이 되면 같은 것(T2)을 학교 사이트에서도 해 보게 하고 걸린 시간을 비교한다 [제안]. 발표에서 쓸 수 있는 숫자다.

## 4. 폼 문항 (구글 폼으로 옮길 것)

| 번호 | 문항 | 형식 |
|---|---|---|
| Q1 | 단과대 | 객관식 (목록) |
| Q2 | 학년 | 객관식 (1·2·3·4·대학원) |
| Q3 | 기숙사에 사나요? | 객관식 (예·아니오) |
| Q4 | 최근 한 학기 동안 장학·행사·학과 공지를 놓친 적이 있나요? | 객관식 (있다·없다·모르겠다) |
| Q5 | 지금 공지를 주로 어디서 보나요? | 객관식 여러 개 고르기 (학교 사이트·학과 사이트·단톡방·에타·친구·안 본다·기타) |
| Q6 | 이 사이트가 공지 찾는 문제를 얼마나 풀어 주나요? (문제 해결 만족도) | 5점 척도 |
| Q7 | 쓰기 편했나요? (사용 편의성) | 5점 척도 |
| Q8 | 보여 주는 정보를 믿을 수 있었나요? (정보 신뢰도) | 5점 척도 |
| Q9 | 다음 주에도 들어올 것 같나요? (재사용 의향) | 5점 척도 |
| Q10 | 가장 쓸모 있던 기능 | 객관식 (모아 보기·마감 표시·내 학과·학식·북마크·일정 달력·기타) |
| Q11 | 내 학과를 넣었나요? | 객관식 (넣었다·안 넣었다) |
| Q12 | (안 넣었다면) 왜 안 넣었나요? | 주관식 |
| Q13 | 학년에 따라 보고 싶은 게 달랐나요? (학년 입력이 필요했는지) | 객관식 (그렇다·아니다) + 주관식 |
| Q14 | 없어서 아쉬웠던 정보나 기능 | 주관식 |
| Q15 | 헷갈렸거나 불편했던 곳 | 주관식 |
| Q16 | 자유 의견 | 주관식 |

Q6~Q9 는 과제 평가지표(사용 편의성 · 문제 해결 만족도 · 재사용 의향)와 맞춘 것이다. Q11~Q13 은 06 에 남긴 결정(첫 화면은 바로 홈, 학과는 선택 / 학년은 뺀다)을 확인하려는 것이다.
